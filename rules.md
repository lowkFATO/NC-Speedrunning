# Game rules
- Paid checkpoints are **not** allowed.
- Banned glitches:
  - [Level State Manipulation (Old Versions only)](https://github.com/lowkFATO/NC-Speedrunning/blob/main/game-mechanics.md)
- Emulators are allowed. You can use any, although <a href="https://play.google.com/googleplaygames" target="_blank">this one</a> is recommended.
  > Using default keyboard controls is not allowed, you have to map A and D keys to tap inputs (on sidebar, select Game controls -> Edit -> Tap), or your run will be **INVALID**. If done correctly, you'll see Movement Buttons animation when pressing the keys.

# Video Submission rules
- The recording must have a level selection screen.
- The recording must be uninterrupted, whole game screen should be visible.
- The run must be uploaded to YouTube and be accessible at all times. If the video is deleted/set to private, the run will be removed from the leaderboards.
- Timing starts at the first frame of the level transition (blue stripes) screen and ends at the first frame of Cat collecting the orb.

> You can time your runs with [Somewes.](https://somewes.com/frame-count/)

> Timing rules don't account for pause. That means you can't take breaks/use pause buffering if you want to get the best possible time.

> Audio recording is not required.
